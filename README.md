# Salon Experiment & Causal Analysis

## Project Overview
This project demonstrates how data science and statistical methods can evaluate a hypothetical customer retention campaign for a salon business.

## Objectives
- Design an A/B testing experiment.
- Check randomisation balance and Sample Ratio Mismatch (SRM).
- Estimate treatment effects and confidence intervals.
- Perform Difference-in-Differences (DiD) analysis.
- Analyse customer segments.
- Apply CUPED variance reduction.
- Develop data-driven business recommendations.

## Tools and Technologies
- Python
- Google Colab
- Pandas and NumPy
- Matplotlib and Seaborn
- SciPy and Statsmodels
- Scikit-learn

## Dataset
The datasets are simulated for educational purposes because real salon data was not provided. They do not represent actual business records.

## Project Files
- `Salon_Experiment_Causal_Analysis.ipynb` – Python analysis notebook
- `Salon_Experiment_Analysis_Report.docx` – Final project report
- `salon_experiment_data.csv` – Initial simulated dataset
- `salon_ab_experiment.csv` – Simulated A/B testing dataset

## Methods Used
A/B Testing, Hypothesis Testing, Bootstrap Confidence Intervals, Difference-in-Differences, Customer Segmentation and CUPED.

## Conclusion
This project demonstrates the use of experimental design and causal analysis to support business decisions. Real-world validation is necessary before applying these findings to an actual salon business.
